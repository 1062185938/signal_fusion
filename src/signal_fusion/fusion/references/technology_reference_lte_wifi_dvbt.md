# LTE、WiFi 与 DVB-T 物理解释参考

## 1. 文档用途

本文档用于解释 `signal_fusion` 当前公开数据集实验中的三类标签：
`LTE`、`WiFi` 和 `DVB-T`。它把通信体制背景与现有 64 维 IQ 特征建立
定性联系，供大模型判断全局特征对 IQ ensemble 结论是：

- `support`：特征与模型标签相容，并提供了一定的独立物理支持；
- `conflict`：多组相互关联但来源不同的特征共同显示实质冲突；
- `insufficient`：特征只表现出三类共享的性质，无法提供类别区分。

本文档不是新的分类器，不提供类别模板、数值阈值或概率，也不能代替三篇
特征定义文档。分析具体数值前，仍须完整阅读：

- `time_domain_iq_features.md`；
- `frequency_domain_iq_features.md`；
- `time_frequency_iq_features.md`。

## 2. 当前证据的观测边界

当前公开数据集实验对每个连续 region 使用以下观测合同：

| 项目 | 当前口径 |
|---|---|
| 有效采样率 | 1 MS/s |
| region 长度 | 4096 个复数 IQ 点 |
| 观测时长 | 4.096 ms |
| 特征粒度 | 对完整连续 region 只提取一次 64 维特征 |
| 预处理 | 对完整 region 统一去直流、统一复 RMS 归一化 |
| IQ 模型粒度 | region 内全部非重叠局部窗口 |

公开数据集包含六个采集地点，数据集作者明确指出不同地点具有不同的信号
强度和噪声特性。因此，地点、传播环境和接收条件造成的分布变化不能被误写
成某种制式固有的物理特征。

### 2.1 只能观察到接收带宽内的局部视图

1 MS/s 的复采样最多描述当前接收基带内约 1 MHz 的频谱视图。若实际无线
信道比它更宽，当前 region 只是信道的一部分。因此：

- 不能用 `freq_normalized_occupied_bandwidth_90` 反推出协议标准带宽；
- “接近整个观测带宽”只表示能量铺展到当前 1 MHz 视图的大部分；
- “较窄”也可能来自接收机只对准实际信号的一部分、滤波或频偏；
- 不能将标准规定的 LTE、WiFi 或 DVB-T 信道带宽直接与归一化特征比较。

### 2.2 绝对功率信息已经被移除

region 级 RMS 归一化使不同 region 具有统一的整体尺度。因此
`time_rms_amplitude` 和 `freq_log10_band_power` 主要用于检查当前向量内部的
数值状态，不能表示原始
接收功率，也不能用于比较地点、增益或类别的绝对强弱。

### 2.3 盲测不得使用采集捷径

当前数据集中，中心频率与类别高度相关，因而中心频率会构成标签捷径。公开
盲输入故意不提供中心频率、地点、增益、来源路径和真实标签。解释时不得猜测
或要求这些信息，也不得从匿名案例编号推断类别。

## 3. 三类信号的共同点

三类标签之间存在很强的共享结构：

- LTE 的下行物理层采用 OFDM/OFDMA；LTE 上行采用 DFT-spread OFDM。当前
  数据集没有在盲证据中说明链路方向，不能默认一定是下行。
- WiFi 是包含多种 PHY 的协议族。常见 802.11a/g/n/ac 类信号使用 OFDM，
  但仅凭 `WiFi` 标签不能推断具体版本、带宽或调制阶数。
- DVB-T 使用多载波 OFDM，并包含保护间隔、连续与散布导频等结构。

多载波信号由许多子载波叠加后，时域包络可能表现出较高峰均比和近似噪声状
统计。因此，较高 PAPR、较高幅度熵、较分散的频谱或近高斯幅度统计可以与
这些类别相容，但通常不能区分 LTE、WiFi 和 DVB-T。

噪声、邻道干扰、频偏、采集滤波和只观察局部频带，也都可能产生相似表现。

## 4. 类别级定性背景

下表只描述“可能观察到的倾向”，任何一项都不是类别判据。

| 类别 | 可能观察到的结构 | 当前 4.096 ms / 1 MHz 视图下的主要限制 |
|---|---|---|
| LTE | 调度后的多载波资源可能在短 region 内表现为相对稳定的频谱占用；参考信号和时隙结构可能引入周期性 | 业务负载会改变占用；上/下行结构不同；局部 1 MHz 视图不足以恢复完整资源栅格；现有 64 维特征不显式检测 LTE 同步信号或参考信号 |
| WiFi | 无线帧通常是突发发送；如果 region 跨越包边界，包络和局部频谱的时间变化可能更明显；OFDM PHY 内包含前导和数据部分 | region 可能完全落在一个包内部，因而不呈现边界；协议版本未知；现有特征不执行 WiFi 前导相关，不能宣称已经检测到前导 |
| DVB-T | 地面数字电视是广播型 OFDM，活动期间通常具有较持续、较稳定的占用；连续/散布导频可能形成稳定成分 | 只观察完整频道的一小部分；4.096 ms 可能不足以可靠恢复帧级结构；现有特征不检测 DVB-T 导频位置、TPS、载波间隔或保护间隔 |

“持续”与“突发”是相对概念。截取策略、接收门限以及 region 是否覆盖信号
边界会改变所见结果。若 region 内只有一个活动片段，不能仅凭短时稳定性排除
WiFi；若 LTE 业务负载较低，也不能仅凭能量起伏排除 LTE。

## 5. 如何解释现有 64 维特征

### 5.1 时域幅度统计

相关特征包括：

- `time_papr_db`；
- `time_amplitude_skewness`、`time_amplitude_kurtosis`；
- `time_envelope_cv`、`time_amplitude_entropy`；
- `time_c20`、`time_c40`、`time_c41`、`time_c42`；
- `time_differential_phase_std`；
- 多延迟自相关和包络功率自相关特征。

解释原则：

1. 多载波叠加可能使三类信号都表现出较高 PAPR 和噪声状包络，不能将其当作
   某一类的专有特征。
2. 包络波动或幅度分布变化可以提示 region 内存在突发边界、衰落或干扰，
   但不能自动等价为 WiFi。
3. 高阶累积量会受到调制混合、多载波叠加、短观测和噪声影响。当前没有经过
   独立验证的类别阈值，不得根据单个累积量给出类别投票。
4. `time_differential_phase_std` 大只表示相邻采样相位变化分散。多载波、噪声、
   频偏和低信噪比都可能造成该现象；它不等价于扫频，也不证明某种协议。

### 5.2 频域统计

相关特征包括归一化频率、频谱扩展、90% 占用带宽、频谱熵、频谱峰值因子、
频谱平坦度、频谱偏度以及双谱/双相干统计。

解释原则：

1. 这些特征描述当前接收基带内的频谱形状，而不是完整协议频道。
2. 较高频谱熵或平坦度与分散的多载波能量相容，但也与宽带噪声相容。
3. 较高频谱峰值因子或局部尖峰可能来自导频、窄带干扰、残余频偏或有限长度
   FFT，不得直接宣称检测到了 LTE、WiFi 或 DVB-T 导频。
4. 频谱均值、中值、峰值和偏度主要反映信号在当前调谐带宽内的位置与不对称
   程度，容易受到调谐偏差和滤波影响。
5. 双谱和双相干反映非线性相位耦合的统计迹象。当前三类信号均可能因多载波
   聚合、信道和噪声而减弱这些迹象，不能使用未验证阈值区分类别。

### 5.3 时频统计

相关特征包括逐帧谱峰度、谱偏度、谱峰因子、谱平坦度、谱熵、谱质心变化、
频谱扩展、STFT 帧能量 CV、活动帧比例、能量状态跃迁比例，以及 STFT、FSST、
WSST 的主脊线统计。

解释原则：

1. LTE、常见 OFDM WiFi 和 DVB-T 都不是以单一线性扫频脊线为核心的波形。
   对多载波信号强行选出的“主脊线”，通常只是每个时间帧中最强的频率 bin。
2. 脊线斜率接近零不能单独支持任何一个类别；脊线波动较大也不能直接说明
   存在 chirp、跳频或某种协议。
3. `FSSTRidgeEnergyRatio` 或 `WSSTRidgeEnergyRatio` 高，只说明能量在当前算法
   选出的局部主路径附近集中。导频、干扰或滤波后的局部频带都可能造成该值。
4. 对这三类技术，逐帧频谱统计的均值与标准差通常比“脊线属于哪一类”的
   叙述更可靠，但仍需结合时域和频域证据。
5. STFT 活动性特征只描述当前 4.096 ms region 内的相对能量变化；它们可以
   提示局部突发或状态切换，但不能独立确认 WiFi 包边界或长期占空比。

## 6. 何时可以说支持、冲突或信息不足

### 6.1 `support`

只有当多个互补特征组共同与模型标签的定性背景相容，并且不存在明显替代
解释时，才可以使用 `support`。例如，时间变化、频谱变化和包络变化共同显示
region 跨越了一个清晰的突发边界，可以为 WiFi 提供有限支持；仍须说明 LTE
低负载或截取边界等替代解释。

### 6.2 `conflict`

只有实质性、成组的物理证据才构成 `conflict`。单一 PAPR、单一占用带宽、
一条脊线或一个高阶统计量与直觉不符，不足以推翻 ensemble。冲突说明应明确：

- 哪几组特征共同形成冲突；
- 是否存在噪声、局部带宽、频偏或截取位置等替代解释；
- 当前 64 维特征是否真的测量到了所声称的协议结构。

### 6.3 `insufficient`

当特征只显示普通的多载波、宽带、噪声状或短时稳定结构时，应选择
`insufficient`。这是三类共享结构下的正常结论，不代表特征提取失败。

## 7. 禁止的推理方式

解释时不得：

1. 使用中心频率、地点、接收增益、文件名或来源路径判断类别；
2. 把归一化 90% 占用带宽当成协议标准带宽；
3. 把差分相位标准差或主脊线波动直接解释为 chirp；
4. 把稳定脊线直接解释为 OFDM、OQPSK、LTE、WiFi 或 DVB-T；
5. 根据单个特征值创造未经验证的高/低阈值；
6. 将强相关的多个特征当作多次独立投票；
7. 从当前特征推断 WiFi 版本、LTE 链路方向、调制阶数或 DVB-T 模式；
8. 因为特征“没有反对”模型，就声称特征独立支持模型。

## 8. 当前 64 维特征没有显式测量的结构

以下结构不属于 64 维向量，不能在解释 64 维特征时假装已经测量到：

- 完整循环前缀确认、OFDM 同步和符号定时；
- 循环平稳谱或循环自相关；
- WiFi 短/长训练序列相关与包边界检测；
- LTE PSS/SSS、参考信号或资源栅格匹配；
- DVB-T 连续/散布导频、TPS、载波间隔和保护间隔检测；
- 比 4.096 ms 更长时间尺度上的占空比和突发周期（现有活动性特征只覆盖单个 region）。

系统当前另有独立的、冻结的 LTE/DVB-T 候选周期门控。它不属于 64 维特征，
其测量、门限和适用边界由 `ofdm_periodicity_gate_reference.md` 单独定义。该门控
仍不等同于上面列出的完整协议结构检测。
