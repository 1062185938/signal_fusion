# P6-C.1 增量 AWGN 边界测试

本次只补充 2.5 dB 和 0 dB。三个 IQ 模型、周期门控阈值和数据集均保持冻结，
每个 SNR 使用噪声种子 44、45、46、47、48。这里的 SNR 是相对于完整 4096 点
实采 region 功率额外加入的圆复 AWGN，不是采集现场的绝对物理 SNR。

## 总体结果

| 条件 | IQ ensemble | IQ + 周期门控 | IQ 平均错误数 | 门控后平均错误数 | review 比例 |
| --- | ---: | ---: | ---: | ---: | ---: |
| clean | 99.897% | 99.983% | 12.0 | 2.0 | 0.163% |
| 10 dB | 99.832% | 99.902% | 19.6 | 11.4 | 0.259% |
| 7.5 dB | 99.617% | 99.734% | 44.6 | 31.0 | 0.519% |
| 5 dB | 98.773% | 99.057% | 142.8 | 109.8 | 1.873% |
| 2.5 dB | 93.693% | 94.512% | 734.2 | 638.8 | 8.374% |
| 0 dB | 75.645% | 76.514% | 2835.2 | 2734.0 | 19.699% |

2.5 dB 下周期门控平均纠正 95.8 个错误、引入 0.4 个错误；0 dB 下平均纠正
106.6 个错误、引入 5.4 个错误。周期门控仍有正收益，但无法阻止 IQ 分支在低 SNR
下的整体退化。

## 分类别结果

下表格式为 `IQ ensemble / IQ + 周期门控`。

| 条件 | LTE | WiFi | DVB-T |
| --- | ---: | ---: | ---: |
| 10 dB | 99.672% / 99.806% | 99.925% / 99.925% | 99.977% / 99.996% |
| 7.5 dB | 99.198% / 99.440% | 99.907% / 99.907% | 99.988% / 100.000% |
| 5 dB | 97.373% / 97.989% | 99.813% / 99.813% | 100.000% / 100.000% |
| 2.5 dB | 86.340% / 88.119% | 99.813% / 99.813% | 100.000% / 100.000% |
| 0 dB | 47.194% / 49.082% | 99.552% / 99.552% | 100.000% / 100.000% |

2.5 dB 时 LTE 平均有 732.2 个 region 被判成 DVB-T；0 dB 时增加到 2830.4 个。
WiFi 仅有少量样本被判成 DVB-T，DVB-T 没有出现平均错误。因此当前低 SNR 失效
主要表现为 LTE 向 DVB-T 的单向类别偏移，而不是三类同时随机化。

## 边界结论

- 若以 99% 总体准确率为高精度边界，IQ ensemble 的边界位于 5 至 7.5 dB；加入周期门控后的边界位于 2.5 至 5 dB。
- 若以 95% 总体准确率为明显失效边界，两条路径的边界都位于 2.5 至 5 dB。
- 0 dB 已明显超出当前系统的可靠工作区间。
- 后续验证 64 维特征与 LLM 的纠错价值时，优先使用 5 dB。它能产生足够的错误和 review case，同时还没有像 0 dB 那样被噪声全面主导。
