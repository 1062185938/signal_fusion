# 12维 IQ 时域特征说明

本文档用于说明 `extractTimeFeatures.m` 提取的 12 个时域 IQ 特征，主要供大模型理解特征含义、输入输出格式、预处理方式和解释边界使用。

这些特征不是直接的调制类型标签，而是从一个复数 IQ 信号段中提取出的统计描述。大模型在使用这些特征时，应结合多个特征的整体模式进行判断，不应只根据单个特征值直接断定信号体制。

## 1. 输入说明

函数输入为一个复数 IQ 向量：

```matlab
x
```

其中：

| 项目 | 说明 |
|---|---|
| 输入类型 | 复数 IQ 序列 |
| 输入形状 | 一维向量，行向量或列向量均可 |
| 输入含义 | 一个完整的 IQ 信号段 |
| 实部 | I 路采样 |
| 虚部 | Q 路采样 |

输入会被统一转换为列向量并转为 `single` 类型：

```matlab
xIn = single(x(:));
```

## 2. 预处理说明

### 2.1 去除直流分量

输入 IQ 信号首先去除均值：

```matlab
x0 = xIn - mean(xIn);
```

这样可以减小直流偏置、接收机零点偏移或静态偏移对后续统计特征的影响。

### 2.2 计算包络

时域幅度包络定义为：

```matlab
absX0 = abs(x0);
```

后续的 RMS、标准差、PAPR、偏度、峰度、包络变异系数和幅度熵主要基于该包络计算。

### 2.3 数值保护

实现中使用 `epsilon = eps('single')` 避免除零或对零取对数。最终输出前还会检查特征值，如果某个特征为 `NaN` 或 `Inf`，则置为 0。

## 3. 输出说明

函数输出为固定长度的单精度特征向量：

```matlab
features
```

输出格式：

| 项目 | 说明 |
|---|---|
| 输出类型 | `single` |
| 输出尺寸 | `1×12` |
| 输出含义 | 当前 IQ 段的 12 个时域统计特征 |
| 顺序要求 | 特征顺序固定，不能随意调换 |

固定输出顺序如下：

| 序号 | 英文名称 | 中文名称 |
|---:|---|---|
| 1 | RMS | 均方根 |
| 2 | Standard deviation | 标准差 |
| 3 | PAPR_dB | 峰均功率比 |
| 4 | Amplitude skewness | 幅度偏度 |
| 5 | Amplitude kurtosis | 幅度峰度 |
| 6 | Envelope CV | 包络变异系数 |
| 7 | Normalized amplitude entropy | 归一化幅度熵 |
| 8 | Normalized C20 | 归一化 C20 |
| 9 | Normalized C40 | 归一化 C40 |
| 10 | Normalized C41 | 归一化 C41 |
| 11 | Normalized C42 | 归一化 C42 |
| 12 | Differential phase standard deviation | 差分相位标准差 |

## 4. 特征解释

### 1. RMS

**计算对象：** 去直流后的复数 IQ 信号 `x0`。

**含义：** 描述信号整体能量或平均幅度尺度。RMS 越大，通常表示该段 IQ 信号的整体功率水平越高。

**解释作用：** 可用于判断信号整体强弱，也可作为其他幅度特征的背景信息。

**注意事项：** RMS 对接收增益、距离、衰减和归一化方式敏感。不同样本之间如果没有统一幅度归一化，不能只凭 RMS 判断调制类型。

### 2. Standard deviation

**计算对象：** 包络 `absX0`。

**实现口径：**

```matlab
std(absX0)
```

**含义：** 描述包络幅度围绕平均值的波动程度。数值越大，说明信号包络起伏越明显。

**解释作用：** 可用于区分幅度较稳定的信号和幅度变化较明显的信号。

**注意事项：** 这里的 `Standard deviation` 实际是包络标准差，即 `std(|x|)`，不是直接对复数 IQ 做标准差。由于它仍受绝对幅度影响，解释时应结合 RMS 和 Envelope CV。

### 3. PAPR_dB

**计算对象：** 包络功率 `absX0.^2`。

**实现口径：**

```matlab
PAPR = max(absX0.^2) / mean(absX0.^2)
PAPR_dB = 10 * log10(PAPR)
```

**含义：** 描述最大瞬时功率与平均功率之间的比例。数值越大，说明信号中越可能存在明显峰值。

**解释作用：** 对通信信号很有解释价值。例如，恒包络或近似恒包络信号通常 PAPR 较低，而 OFDM 类信号可能具有较高 PAPR。

**注意事项：** PAPR 对孤立尖峰、噪声脉冲、截断异常和 AGC 变化敏感。高 PAPR 只能说明峰值相对平均功率较高，不能单独等同于 OFDM 或某一具体制式。

### 4. Amplitude skewness

**计算对象：** 包络 `absX0` 的中心化结果。

**含义：** 描述幅度分布的不对称程度。正偏度通常表示大多数幅度值较低，但存在少量较高幅度样本。

**解释作用：** 可辅助理解包络分布形态，判断幅度样本是否偏向某一侧。

**注意事项：** 偏度对异常值较敏感。当信号段较短或噪声较强时，该特征可能不稳定。

### 5. Amplitude kurtosis

**计算对象：** 包络 `absX0` 的中心化结果。

**含义：** 描述幅度分布的尖锐程度和尾部强度。数值较高时，通常表示幅度分布中存在较明显的尖峰或重尾。

**解释作用：** 可用于描述包络是否集中、是否存在较强的极端幅度样本。

**注意事项：** 当前实现计算的是普通峰度，不减去 3，因此不要按“超额峰度”的定义解释。峰度同样对异常值敏感。

### 6. Envelope CV

**计算对象：** 包络 `absX0`。

**实现口径：**

```matlab
Envelope CV = std(absX0) / mean(absX0)
```

**含义：** 描述包络的相对波动程度。它不是看绝对幅度有多大，而是看包络相对于自身平均值变化得有多明显。

**解释作用：** 可用于比较不同功率尺度下的包络稳定性。相比 Standard deviation，它对整体幅度缩放更不敏感。

**注意事项：** 当平均包络非常小，即信号接近全零或噪声很弱时，该特征可能不稳定，因此实现中使用了 `epsilon` 做数值保护。

### 7. Normalized amplitude entropy

**计算对象：** 包络 `absX0` 的直方图分布。

**实现口径：** 当前实现使用 10 个等宽幅度区间统计概率，并将香农熵除以最大熵 `log2(10)`：

```matlab
H_norm = H / log2(10)
```

**含义：** 描述幅度取值分布的离散程度或不确定性。数值越接近 0，说明幅度更集中；数值越接近 1，说明幅度分布更分散。

**解释作用：** 可辅助判断包络幅度是否集中在少数范围，或是否覆盖较宽的幅度区间。

**注意事项：** 该特征受直方图区间数、幅度范围和样本数量影响。它是包络分布复杂度指标，不是信息速率或通信编码熵。

### 8. Normalized C20

**计算对象：** 去直流后的复数 IQ 信号 `x0`。

**实现口径：**

```matlab
M20 = mean(x0.^2)
M21 = mean(absX0.^2)
C20 = abs(M20) / M21
```

**含义：** 描述复信号二阶矩中的非圆对称成分。取绝对值和能量归一化后，可减小整体增益和初始相位的影响。

**解释作用：** 对不同调制方式的复平面统计结构有一定区分能力，常用于通信调制识别中的高阶统计特征体系。

**注意事项：** C20 不是单独的调制判决规则。其数值会受噪声、频偏、定时偏差、滤波和样本数量影响。

### 9. Normalized C40

**计算对象：** 复数 IQ 信号的四阶矩和二阶矩。

**实现口径：**

```matlab
C40 = abs(M40 - 3 * M20.^2) / M21.^2
```

**含义：** 描述复信号四阶累积量结构，可反映星座形状、幅度分布和高阶统计特性。

**解释作用：** 常用于调制识别，因为不同调制方式在高阶累积量上可能呈现不同统计模式。

**注意事项：** C40 对信噪比和样本长度敏感。低信噪比下，它的解释可靠性会下降。

### 10. Normalized C41

**计算对象：** 复数 IQ 信号的混合四阶矩。

**实现口径：**

```matlab
C41 = abs(M41 - 3 * M20 * M21) / M21.^2
```

**含义：** 描述复信号在三次原信号和一次共轭信号组合下的四阶累积统计结构。

**解释作用：** 可补充 C40 和 C42，从不同高阶统计角度描述 IQ 样本的复平面分布。

**注意事项：** 与其他累积量一样，C41 应作为组合特征使用，不应孤立解释。实际数值会随预处理、归一化和信道条件变化。

### 11. Normalized C42

**计算对象：** 复数 IQ 信号的四阶幅度矩及二阶矩。

**实现口径：**

```matlab
C42 = abs(M42 - abs(M20).^2 - 2 * M21.^2) / M21.^2
```

**含义：** 描述复信号四阶幅度相关累积量。它与信号星座点分布、幅度集中程度和高阶统计形态有关。

**解释作用：** 在高阶累积量特征组中，C42 是较常用的统计量之一，可与 C20、C40、C41 共同描述通信信号的统计结构。

**注意事项：** C42 受噪声、滤波、采样数量和幅度归一化影响。解释时应优先看累积量组的整体模式。

### 12. Differential phase standard deviation

**计算对象：** 相邻复数 IQ 样本之间的差分相位。

**实现口径：**

```matlab
differentialPhase = angle(x0(2:end) .* conj(x0(1:end-1)))
std(differentialPhase)
```

**含义：** 描述相邻采样点相位变化量的波动程度。数值越大，说明相位增量变化越不稳定。

**解释作用：** 可辅助描述频率变化、相位连续性、调制相位跳变或噪声引起的相位扰动。

**注意事项：** 该特征对载波频偏、采样率、低幅度样本噪声和相位噪声敏感。当前实现使用相邻样本乘共轭再取 `angle`，可以消除恒定初始相位的影响，但不能完全消除频偏影响。

## 5. 大模型使用建议

### 5.1 推荐解释方式

大模型理解这 12 个特征时，可以按以下分组：

| 分组 | 特征 | 主要描述 |
|---|---|---|
| 能量尺度 | RMS | 信号整体能量水平 |
| 包络波动 | Standard deviation、Envelope CV、PAPR_dB | 幅度变化、相对波动和极端峰值 |
| 幅度分布形态 | Amplitude skewness、Amplitude kurtosis、Normalized amplitude entropy | 包络分布是否偏斜、尖锐或分散 |
| 高阶复统计 | Normalized C20、C40、C41、C42 | 复平面统计结构和调制相关高阶特征 |
| 相位变化 | Differential phase standard deviation | 相邻样本相位变化稳定性 |

### 5.2 不建议的解释方式

不建议让大模型做以下推断：

| 不建议做法 | 原因 |
|---|---|
| 只根据 RMS 判断信号类型 | RMS 受接收功率和增益影响很大 |
| 只根据 PAPR_dB 判断是否为 OFDM | 高 PAPR 也可能来自噪声、脉冲或截断异常 |
| 把幅度熵理解为通信系统的信息熵 | 这里的熵只是幅度直方图熵 |
| 只根据一个累积量判断调制方式 | 高阶累积量需要组合使用 |
| 忽略采样率和频偏解释差分相位标准差 | 相位差分特征明显受采样和频偏影响 |

### 5.3 更合理的理解方式

这 12 个特征应被理解为一个固定顺序的时域统计特征向量：

```text
[RMS,
 Standard deviation,
 PAPR_dB,
 Amplitude skewness,
 Amplitude kurtosis,
 Envelope CV,
 Normalized amplitude entropy,
 Normalized C20,
 Normalized C40,
 Normalized C41,
 Normalized C42,
 Differential phase standard deviation]
```

其中：

- 前 7 个特征主要描述幅度、能量、包络和幅度分布；
- 第 8 到第 11 个特征描述复数 IQ 的高阶统计结构；
- 第 12 个特征描述相邻采样点的相位变化稳定性。

大模型在解释时应关注特征之间的组合关系，例如：

- RMS 高但 Envelope CV 低：可能表示整体能量较强，但包络较稳定；
- PAPR_dB 高且 kurtosis 高：可能表示存在明显峰值或重尾幅度分布；
- Envelope CV 高且 amplitude entropy 高：可能表示包络变化范围较宽；
- C20、C40、C41、C42 的组合变化：可能反映复平面统计结构差异；
- Differential phase standard deviation 高：可能表示相位变化更复杂或更不稳定。
